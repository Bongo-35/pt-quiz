# 理学療法士 学習クイズ

理学療法士（PT）や理学療法士を目指す学生が、国家試験対策や知識の復習に使える4択クイズアプリです。
HTML ファイル1つで動くので、インストールは不要です。

**▶ 公開ページ：https://bongo-35.github.io/pt-quiz/**

## 特徴

- 全200問・4択形式（基礎〜応用ミックス）
- 解答するとすぐに正誤と解説を表示
- 出題順は毎回ランダム
- 最後に総得点・正答率・分野別の成績を表示
- スマートフォン対応、ダークモード対応

## 問題の追加・編集

問題は `index.html` の `<script>` 内にある `QUESTIONS` 配列にまとめて書かれています。
次の形式で1問ずつ追加します。

```js
{cat:"anat", diff:"基礎", q:"安静時の主要な吸気筋として最も重要な筋はどれか。",
 choices:["横隔膜","内肋間筋","腹直筋","広背筋"], correct:0,
 explanation:"横隔膜は安静吸気時の約70~80%の換気を担う主要な吸気筋である。"},
```

| 項目 | 内容 |
| --- | --- |
| `cat` | 分野（`CATEGORIES` にある `key` のどれか：`anat` / `kine` / `dis`） |
| `diff` | 難易度（`"基礎"` または `"応用"`） |
| `q` | 問題文 |
| `choices` | 選択肢（数は自由。画面では A, B, C… と自動でラベルが付く） |
| `correct` | 正解の番号（**0から数える**。A=0, B=1, C=2, D=3） |
| `explanation` | 解説文 |

問題数（「全24問」などの表示）は自動で数えられるので、問題を足すだけで大丈夫です。

### 新しい分野を追加するとき

`index.html` の `<script>` の先頭にある `CATEGORIES` に1行足すだけです。
分野名の表示、ラベルの色、結果画面の分野別成績はすべて自動で反映されます。

```js
const CATEGORIES = [
  {key:"anat", label:"解剖学・生理学",   color:"#2f6fed"},
  {key:"kine", label:"運動学・運動療法", color:"#8a4fd6"},
  {key:"dis",  label:"疾患別理学療法",   color:"#d67a1f"},
  {key:"ortho", label:"運動器理学療法",  color:"#1f9d8a"},  // ← 例：追加した分野
];
```

追加したら、その分野の問題は `cat:"ortho"` のように書きます。

## 注意事項

- このアプリは学習用です。実際の臨床判断は、最新のガイドラインや指導者の判断に従ってください。
- 国家試験の過去問をそのまま載せる場合は、著作権と出典の扱いに注意してください。
- 問題や解説に誤りを見つけたら、教科書やガイドラインで確認してから直してください。
